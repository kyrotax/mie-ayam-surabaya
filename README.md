# Mie Ayam System

Monorepo arsitektur sistem Mie Ayam Surabaya.

## Struktur Direktori
- `docs/`: Dokumentasi API contract, ERD, dan Flow sistem.
- `web/`: Next.js frontend dan backend BFF (deploy ke Vercel).
- `ml/`: FastAPI ML service untuk OCR & entity extraction (deploy ke Railway/Render/Fly/VPS).
- `data-science/`: Dataset, notebooks, evaluasi model, dan analitik.
